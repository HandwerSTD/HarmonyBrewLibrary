## 主线定稿（2026-11-22 终裁，叙事全文已落地为 `motivation.md` v3：场景开场 / 四想法 / 功能平铺，无论证章节）

**主线一 · 选型信任 ——「像挑选软件一样挑选 CLI」**
断层：老手十年的选型直觉（什么任务用什么、哪个是主流、哪个还活着）从未产品化；应用商店用评分/评论/榜单解决了 GUI 世界的信任，命令行世界至今靠搜索运气与博客施舍。
功能点：现状即证据（六榜真实下载量现算 / 16 分类 / 离线搜索，v1.4 已建成）+ 4 趋势线（还活着吗）+ 3 速递（上新）+ 6 AI 工具榜。（终裁：22 溯源卡、食品安全节删除，见 `rejected.md` §1 第 16 / 17 条。）

**主线二 · 随叫随到的老手 ——「不嫌你问题蠢，有问必答」**（命名备选：口袋里的老手 / 不再瞎猜；标题不放 AI 字样，AI 归技术章）
断层：师徒制消失、提问有社交成本（RTFM / SO 不友好 / 博客过时），新人的真实策略是瞎猜硬扛。
功能点：7 问包 / 8 问需求 / 9 问报错 + 15 tldr（师父手写的例子）。
为什么是现在：LLM 让「给 16,356 个包各配一个讲解员」从人力荒谬变成一次调用。
**技术章（AI 赋能）**：四层——grounding 不瞎说 / 确定性降级 / BYOK 主权 / 32 系统级操控（**AI 用了 BrewLibrary**：Skill 暴露 search / preview / install / query）+ 灵魂问答页（「Agent 都能执行命令了还要你们干什么」→ 状态 / 口径 / 护栏 / 防幻觉 slopsquatting）。

**主线三 · 装完之后，有人管 ——「命令行不缺力量，缺护栏」**
断层：GUI 默认的照顾体系（确认框 / 回收站 / 版本回滚 / 存储管家）在命令行世界全部缺失。用需求方自己的两句话开场：「怕破坏性更新」（动手时刻）+「懒得管」（平时）。
结构说明：原「自动照顾」独立线**合并**至此线作「平时」半场（两拍共享同一断层，deck 密度考虑；如需拆回四线亦成立，H/F/F+ 反正在第一梯队）。
功能点：动手时刻——16 装机预演 / 12 卸载安全网 / 18 版本回滚 / 29 装后待办；平时——13 更新哨兵 / 11+14 磁盘管家 / 10 体检（可选）。

**主线四 · 工具链跟着人走 —— 跨设备软件包同步（鸿蒙多设备能力承载）**
功能点：B′ 路径② Brewfile 导入（逐条标注适配态 → 勾选批量安装）+ 31 W′ 工具清单同步（只同步主动安装的库；v0 文件流 / v1 账号云同步默认关）。场景：换机一键复制环境 + 双机互见（dotfiles 文化人群自证）。
